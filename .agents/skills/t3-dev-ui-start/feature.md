1. Pin Page Context button
   Adds current URL/title/DOM summary into the prompt automatically so the agent has exact page context.

2. Action Recorder
   Records clicks, types, and navigations, then inserts a reproducible step list into chat.

3. Element-to-Code Jump
   Click an element in inspect mode and map it to likely source file/component paths in your repo.

4. Visual Diff Mode
   Capture before/after screenshots and highlight changed regions.

5. Network Mini Panel
   Show failed requests, slow requests, status codes, and payload snippets while testing flows.

6. Storage/Cookies Editor
   Quickly inspect and edit localStorage, sessionStorage, and cookies for auth/debug flows.

7. Accessibility Quick Scan
   Run a lightweight a11y pass and list actionable issues tied to visible elements.

8. Session Presets
   Save named browser states (tabs + auth + viewport) and restore them in one click.

9. Chat Import + Grounded Citations (Planned)
   Import a ChatGPT transcript into a new desktop thread and continue from a structured handoff.
   Preserve and render grounded-search citations so sources remain visible, auditable, and reusable in follow-up turns.
